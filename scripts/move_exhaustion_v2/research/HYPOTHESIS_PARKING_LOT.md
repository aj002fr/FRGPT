# Move Exhaustion V2 — Hypothesis Parking Lot

Post-hoc ideas, mid-experiment observations, and "we should also test…" thoughts
land **here**, never in a running experiment. Nothing in this file is evidence,
and nothing here may alter a frozen contract, add cells to a running FDR family,
or retune parameters on data that has already been inspected.

**Promotion path (the only way out of the lot):**

1. Idea recorded here with full provenance (below).
2. If the motivating data has already been inspected, the idea can only be
   tested on data not yet consumed for that purpose (e.g., a future preregistered
   experiment on untouched dates) — the FDR clock starts fresh in its own family.
3. User approves a new preregistered contract under `experiments/` (dated
   addendum in `research/PROGRAM.md` §10).
4. Only then may it run.

```
- Earliest legitimate test: (which future experiment/cohort could test it cleanly)
- Status: PARKED | PROMOTED (date, contract) | RETIRED (date, reason)
```
